# Contributing

Thanks for contributing to nestjs-idempotency-key.

## Development

1. Create a branch from development.
2. Install dependencies with npm ci.
3. Run tests with npm test.
4. Run the build with npm run build.
5. Open a pull request into development.

Changes intended for a release should flow from development to main through a pull request.

## Pull requests

Keep changes focused, add tests for behavior changes, and update the README for public API changes.
